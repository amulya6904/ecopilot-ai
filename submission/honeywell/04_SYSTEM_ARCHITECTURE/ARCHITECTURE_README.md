# Architecture deliverable

`SYSTEM_ARCHITECTURE.md` is the final system-architecture document for the
Honeywell deliverables 1–4 package. It covers the complete EnergyPlus-first
closed loop, MCP schemas and permissions, local Qwen advisory boundary,
prompt/latency/log management, deterministic safety authority, runtime
actuation, auditability, comparison, classification, and reproducibility.

The document describes the validated prototype scope. It does not claim a
production deployment, safety certification, direct LLM actuation, native PMV,
or site-calibrated tariff/carbon inputs.
